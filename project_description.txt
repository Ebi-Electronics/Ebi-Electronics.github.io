В этом файле находится описание проекта, которое должно помочь ИИ разработке
Сайт (html страницы) генерируются при помощи Pelican.
Сайт является блогом в котором есть отдельные посты и проекты

Сборка версии сайта для публикации осуществляется при помощи pelican content
Тестовые версии собираются при помощи pelican -lr

В папках output и docs находятся сгенерированные пеликаном страницы, которые нельзя
изменять вручную. Docs нужно для правильного хоста на GitHub Pages.

В папке content находится содержимое сайта, которое редактируется автором, не ИИ.

pelicanconf.py — Главный конфигурационный файл - настройка всего: название сайта,
 имя автора, часовой пояс, подключаете плагины, путь к теме оформления и так далее.

publishconf.py — Настройки для публикации (продакшена). Этот файл импортирует настройки
 из pelicanconf.py, но переопределяет некоторые из них для сайта.
 Например, здесь прописывается абсолютный URL вашего сайта (SITEURL), включается
 генерация RSS/Atom лент, добавляется аналитика (Google Analytics) или система
 комментариев (Disqus).

В папке themes находится тема оформления сайта. 

tasks.py - скрипты помошники для сборки сайта

В основном для ИИ разработки должны использоваться pelicanconf, publishconf и папка themes.

Для отображения формул добавлено расширение pelican-render-math - его нужно установить на комьютере выполняющем сборку.

---
Изменения функционала (17.04.2026)

Автокопирование в docs:
- После каждого pelican content папка output автоматически копируется в docs.
  Реализовано через сигнал Pelican signals.finalized в pelicanconf.py.

Поиск (Pagefind):
- Установлен пакет pagefind[bin].
- После копирования в docs запускается индексация: python -m pagefind --site output
  и python -m pagefind --site docs. Индекс сохраняется в output/pagefind/ и docs/pagefind/.
- Виджет поиска подключён в sidebar (base.html), элемент #pagefind-search.
- Все страницы кроме статей исключены из индекса через data-pagefind-ignore="all" на <body>.
  Только article.html переопределяет этот блок, разрешая индексацию.
- Поиск работает только после pelican content (не в режиме pelican -lr).

Страница archives (список постов):
- Создан шаблон themes/editoral/templates/archives.html.
- Показывает все посты от новых к старым в одну колонку с превью.
- Ссылка Posts в меню ведёт на /archives.html.

Пагинация страницы archives:
- В pelicanconf.py добавлено: PAGINATED_TEMPLATES = {'archives': None}
- Pelican генерирует archives.html, archives2.html и т.д. по 10 постов на страницу
  (DEFAULT_PAGINATION = 10).
- Шаблон archives.html использует переменные articles_page, articles_previous_page,
  articles_next_page и articles_page.paginator.page_range.
